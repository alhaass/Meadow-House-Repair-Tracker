# Meadow-House-Repair-Tracker

## Run it

Install `index.html`. Then, open it in any modern browser.

## Notes
- Jobs, statuses, notes and history are saved in the browser's `localStorage`, so they survive a refresh.
- All typed text is rendered with `textContent`, so HTML-looking text such as `<b>check gate</b>` is shown literally.
- No frameworks, accounts, paid services or API keys. All data is fictional.
